# 人生下一站 · 城市性格测试

24 道情境题，80 座城市（国内40、海外40），纯静态单文件网页，无需安装依赖。

## GitHub Pages 部署

将 index.html 上传到仓库根目录，在仓库 Settings → Pages 选择 Deploy from a branch，选择 main 分支与 / (root)，保存。部署完成后使用 Pages 显示的网址。

也可在支持静态站点的平台连接此仓库，发布目录设置为仓库根目录，无需构建命令。

## 验证

已完成六维计分、80城可达性、6000组随机答案检查。
已在390×844浏览器视口完成24题、结果展示与PNG下载测试，尚未在实体手机测试。
